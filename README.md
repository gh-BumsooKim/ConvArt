# ConvArt

**Convention-Aware Creative Synthesis via Diffusion for Design Domains**

Bumsoo Kim, Sanghyun Seo — Chung-Ang University
SIGGRAPH Asia 2026, Technical Communications

Given two design inputs, ConvArt synthesizes a novel design that blends both while
preserving the drawing conventions of each — rendering style, structure and palette.
An orthogonal tuning scheme specializes a pre-trained diffusion model to a single
input pair in about one minute on a consumer GPU.

**Project page:** https://bumsookim00.com/ConvArt/

Code and demo are not released yet.
